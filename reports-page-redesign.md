# Redesign da página de relatórios

## Objetivo
Dar hierarquia aos indicadores de vendas e operação, melhorar a leitura dos gráficos e otimizar a renderização das seções extensas sem alterar cálculos.

## Tarefas
- [x] Destacar faturamento e organizar KPIs por prioridade.
- [x] Reestruturar gráficos e insights em blocos responsivos.
- [x] Separar visualmente vendas e chamados das mesas.
- [x] Melhorar tabelas e cartões para telas pequenas.
- [x] Adiar a renderização visual das seções fora da viewport.
- [x] Validar tipos, lint, testes e build de produção.

## Concluído quando
- [x] A página estiver mais clara em desktop e mobile, usando os temas existentes e os mesmos dados e cálculos.
